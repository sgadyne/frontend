# Frontend ownership

Keep this repository reusable: components, interaction/session state, normalized contracts, caller-supplied provider interfaces, explicitly synthetic demos, and the static public/default market-universe bundle under `assets/market-universe`. Keep provenance and known rights notices with supplied metadata and artwork.

Do not add private app identities, binding defaults, environment/profile selections, deployment-specific source locations, credentials, live or captured observations, private configured universe membership, consumer branding, vendor SDK clients or backend calculations. Consumer deployments compose the components and own their actual identifiers, manifests, readers and settings.

Preserve public component contracts. Existing installed identities and environment-selected membership belong to consumer compositions, not this repository. Keep synthetic fixtures labelled and disconnected from real-source fallbacks. Run the boundary audit and affected type/build/browser checks after changing integration seams.
