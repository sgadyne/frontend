# Frontend ownership

Keep this repository reusable: components, interaction/session state, normalized contracts, caller-supplied provider interfaces and explicitly synthetic demos.

Do not add private app identities, binding defaults, environment/profile selections, concrete source locations, credentials, captured data, firm catalogues, company branding, vendor SDK clients or backend calculations. Consumer deployments compose the components and own their actual identifiers, manifests, readers and settings.

Preserve public component contracts. Existing installed identities belong to consumer compositions, not this repository. Keep synthetic fixtures labelled and disconnected from real-source fallbacks. Run the boundary audit and affected type/build/browser checks after changing integration seams.
