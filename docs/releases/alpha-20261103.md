# Market directory alpha — 2026-11-03

This frontend cohort accompanies Sampo 1.0.0-beta.4, using SDK protocol 0.2.0-alpha.20261102.5. No data-engine upgrade or backend market jobs are required. The four independent OCI examples (Risk, VFO, Cluster and Replication) are version 1.2.1; identities are unchanged.

## Directory and default view

The static directory retains 210,576 records. This is a listing inventory, not a company count: 60,483 warrants, 48,260 bonds, 58,027 equity listings, 27,489 ETF listings, and other classes. Issuers and funds may have several venue-qualified listings. Dates and source scopes vary; see [coverage](../../assets/market-universe/COVERAGE.md).

New VFO views start with **Equities & ETFs** (common equities, depositary receipts, REITs and ETFs). All instruments, including debt and warrants, remain available through the type selector. Explicit saved filters survive unchanged. Region changes preserve the instrument scope. Existing saved all-instrument views are not silently rewritten.

Artwork has 529 authentic listing bindings at this checkpoint; most records use labelled fallback badges. This is not complete logo coverage. An independent artwork expansion follows this release. Packaged VFO includes metadata/artwork rights notices and coverage qualifications.

## Distribution

Node 24 is recommended. Run npm ci, npm run check, then node examples/sampo-installed-apps/build.mjs. Release OCI archives are prebuilt examples; index.json contains the immutable package digest and SHA256SUMS verifies archive integrity. Import through the deployment's OCI stage/review/install workflow. Updating saved workspace pins is separate from installation; preserve configuration, view state, layouts and session identities.

Examples show synthetic coverage, with no live data requests or submitted backfill jobs. Corporate consumers provide readers and configuration.

## Evidence and limits

Directory base f1d2871 passed 57 model tests, 10 importer fixtures, integrity, type/build/OCI and nested-mount browser checks. Its 783 ms first render is a Linux headless-browser measurement, not a network/corporate guarantee. Initial JavaScript is about 277 KB; package catalogue/group JSON still total about 5.5 MB gzip and load once.

The release increment adds focused tests for default filtering, saved scope, portable-state roundtrip and exclusion of debt/warrants from the equity/ETF scope. No unknown instrument class is inferred to be equity.

Known work: authentic logo expansion, official-source gaps in the coverage matrix, optional partitioned loading. Windows native qualification and the complete human-confirmed MCP edit/recovery/publication proof belong to Sampo and are not implied by these frontend checks.
