# Asset catalogue interface

The reusable asset library is `packages/vfo-workspace-core/src/market`: identity, branding, regional/industry boards, sourced fund holdings and classifications. A private or public site supplies the normalized WorkspaceSite contract. `catalog.example.json` is fictitious demo data; it is not a firm coverage catalogue.

Actual copied logos, fund holdings snapshots and the private merged universe are external. Include third-party assets in a distribution only under their applicable redistribution terms, with provenance. Monograms and code-owned UI assets work without external assets.
